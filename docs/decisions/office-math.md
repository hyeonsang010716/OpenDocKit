# Office equation decisions

Deliberate decisions for Office equations in DOCX and PPTX (OMML → LaTeX, `_shared.omml_to_latex`). Split off from [office.md](office.md);
the rule is the same: do not revert the decisions in this table. To change one, change its pinning test first and write the reason in the same row.
The goal is not complete LaTeX but that an LLM can read the structure (fractions, scripts, radicals, brackets, sums).

## Office equations

| Decision | Why | Pinned by |
| --- | --- | --- |
| Office equations (OMML) become ` $LaTeX$ ` in one place, `_shared.omml_to_latex`/`render_omml` (shared by DOCX and PPTX). PPTX keeps an a14:m inside a paragraph in place, and for an `mc:AlternateContent` inside a paragraph mc:Fallback is not read when mc:Choice yields text. Known accepted gap: equations in slide titles and speaker notes are not read | An equation is not a run, so it dropped out without a warning, as in '면적 공식: 입니다' ("the area formula is ."). Reading the fallback as well gives the same equation twice. **Followed the spec only, without a real file saved by PowerPoint (unverified)** | `test_office.py::TestPptxEquations` |
| A fraction without a bar (m:type noBar) is `\binom{n}{k}` when alone inside parentheses (m:d default `(`, `)`) (the parentheses are absorbed), otherwise `{n \atop k}`. Linear and skewed fractions (lin, skw) are `{a+b}/c`. A one-character script immediately followed by a letter or digit is braced (`x^{k}a^{n-k}`; `x^2` as is when an operator or the end follows), and a function name (m:func) is separated by a space from a preceding letter, digit or closing bracket (`a_n cos x`). A group character (m:groupChr) is `\underbrace`/`\overbrace` for ⏟/⏞, otherwise `\overset`/`\underset`. Curly delimiters are `\{`, `\}`, and an equation array inside a delimiter with only an opening `{` (simultaneous equations) is `\begin{cases}…\end{cases}` | The binomial coefficient of Word's built-in equation 'Binomial theorem' read as a division `(\frac{n}{k})`, and scripts were glued to the following characters as `x^ka^{n-k}`, `a_ncos`. Group characters are attributes and were dropped, the braces of `{a,b}` vanished as LaTeX grouping, and simultaneous equations were `\{…` without a closing bracket. Hancom equations (`_equation.py`) use `\binom` too. 0 output changes over 17 example DOCX files (no equations); confirmed with 1 equation document saved by Word (9 Korean built-in equations) | `test_office_equations.py` |
| Tracked changes inside an equation are handled like body paragraphs: the deleted side (m:r wrapped in w:del/w:moveFrom) is left out and the inserted side (w:ins/w:moveTo) is read (`_shared._TRACKED_REMOVALS`) | An equation whose coefficient was corrected 0.3 → 0.5 was `E=A×0.30.5` (the body path `docx._paragraph_text` already skipped it). PPTX has no tracked changes, so sharing the path changes nothing there | `test_office_equations.py::TestOmmlTrackedChanges` |
| For the equation font scripts (m:rPr/m:scr) double-struck, script and fraktur, only letters and digits are wrapped as `\mathbb{R}`, `\mathcal{L}`, `\mathfrak{g}`. Sans-serif, monospace and the like stay as they are. Not converting to Unicode characters (ℝ) is deliberate — it is output as a LaTeX command like other equation structure, and characters missing from Unicode (double-struck lowercase etc.) get the same notation | The real numbers ℝ and naturals ℕ became the same as ordinary variables R and N, and the Laplace transform ℒ the same as L (pandoc saves `\mathbb{R}` in this shape) | `test_office_equations.py::TestOmmlMathAlphabets` |
| A phantom (m:phant) outputs no text when m:show is off (0, off, false) and keeps its inner text when default (on) (size attributes such as zeroWid are ignored) | Phantom text made invisible was joined in too, giving `hiddenx` | `test_office_equations.py::TestOmmlPhantom` |
| When the last element of the base (m:e) of a script (m:sSup, m:sSub, m:sSubSup) is an expression carrying a script on the same side, the base is braced (`{x^2}^3`, `_shared._script_base`). A superscript on a subscript (`a_i^2`) stays as it is | `(x²)³` was `x^2^3` (a LaTeX error, confusable with `x^{2^3}`) | `test_office_equations.py::TestOmmlScriptOnAScriptedBase` |

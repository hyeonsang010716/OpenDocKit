# HTML decisions

Deliberate decisions for HTML blocks (aside, quote blocks, checklists, item/value tables whose name cell is a th), hidden and unrendered elements (`aria-hidden` on an app root, noframes/noembed, datalist), raw-text elements (textarea, xmp, plaintext), ruby, unclosed headings, lazy-loading placeholder pictures, MHTML frames, inline SVG labels and SVG `data:` URI pictures, and `data:` URI pictures embedded in MD (`text.extract_markdown`). Split off from the HTML / text section of [extractors.md](extractors.md);
the rule is the same: do not revert the decisions in this table. To change one, change its pinning test first and write the reason in the same row.

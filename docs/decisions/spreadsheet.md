# Spreadsheet decisions

Deliberate decisions of the Excel and CSV extractors (`spreadsheet.py` for XLSX with `_openpyxl_reading.py` and `_xlsx_parts.py`, `xls.py`, `xml_spreadsheet.py`, `csv_text.py`; number formats in `_sheet_format.py`, rows → tables in `_sheet_layout.py`). Split off from [extractors.md](extractors.md); the rule is the same:
do not revert the decisions in this table. To change one, change its pinning test first and write the reason in the same row.
The decisions about CSV delimiters, quotes and line verdicts (`extract_csv`) are kept separately in [csv.md](csv.md). Decisions shared by CSV and Excel, such as value formatting, are in this file; splitting tables within a sheet, table title rows and filling horizontal merges are in [spreadsheet-tables.md](spreadsheet-tables.md).
Cell values that do not fit the format, pictures in cells, form controls, SmartArt on sheets and default-password XLS are in [spreadsheet-cells.md](spreadsheet-cells.md).

## Excel / CSV

| XLSX uses read_only streaming (no merge information) only when the sheet XML totals over 20 MB | Full load of a 130,000-row sheet 3.6 s, 570 MB → 0.3 s. | defusedxml is not added for XLSX | openpyxl uses lxml with a parser that has entity resolution off and rejects a DTD in a sheet as a parse failure. Adding it would not change this path | `test_converter.py::test_xlsx_dtd_entities_are_never_expanded` |

| Excel format sections: a negative takes the absolute value in the second section, and zero uses the third section only when it has a `0` placeholder. Rounding takes 0.5 away from zero (Decimal) | `+-5.2%`, `▲-1,200`, and 72.5 as 72 went out. The accounting zero section `"-"??` became '-0' | `test_spreadsheet.py::TestNumberFormatSections`, `TestNumberFormatRounding` |
| Stopping after 5,000 empty rows applies to streaming XLSX only, with a warning when it stops. Full load, XLS, CSV and XML read to the end | The total row after a long empty stretch disappeared without a warning | `test_spreadsheet.py::TestEmptyRowGaps` |
| East Asian built-in date formats (27–36, 50–58) decide date vs. time by the value (the shape is not imitated). `[h]` elapsed time is cumulative `26:00` (including numeric XLS cells with a format of only an elapsed section, `[ss]` — xlrd reports them as numeric cells); an XLS date cell below 1 is a time; an XLS error cell is `#REF!` etc. | They went out as serial numbers, `1 day, 2:00:00`, `1899-12-31 09:30` or blank | `test_spreadsheet.py::TestEastAsianBuiltinDateFormats`, `TestElapsedTime`, `TestXlsValues` |

| For `_xHHHH_` in XLSX cell text only control characters (0000–001F) and `_x005F_` are decoded, and CRs are merged into a single line break.

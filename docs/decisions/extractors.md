# Extractor decisions

Deliberate decisions of the per-format extractors. Structure, dependency direction and the common decisions (limits, pictures, assembly) are in [core.md](core.md).
Do not revert the decisions in these tables. To change one, change its pinning test first and write the reason in the same row.

## PDF

Kept separately in [pdf.md](pdf.md) (reading order in [pdf-flow.md](pdf-flow.md); joining fragments of the same row ('item value', the value at the end of a dotted leader, list numbers) and pulling up pushed-down lines in [pdf-rows.md](pdf-rows.md); splitting table cells, header rows of continued tables, checkboxes, header rows of form grids and grouped form values in [pdf-tables.md](pdf-tables.md); resource limits, page boxes and attachments in [pdf-limits.md](pdf-limits.md); fonts without widths and symbol fonts in [pdf-fonts.md](pdf-fonts.md); joining lines of text in ruled-table cells in [pdf-cells.md](pdf-cells.md)).

## HWP / HWPX

Kept separately in [hwp.md](hwp.md).

## DOCX / PPTX / charts

Kept separately in [office.md](office.md); numbering and lists in [office-lists.md](office-lists.md), equations in [office-math.md](office-math.md), charts in [office-charts.md](office-charts.md), processing time in [office-limits.md](office-limits.md).

## Excel / CSV

Kept separately in [spreadsheet.md](spreadsheet.md) (CSV in [csv.md](csv.md); splitting tables and filling merges in [spreadsheet-tables.md](spreadsheet-tables.md); interpreting cell values, pictures in cells, form controls, sheet SmartArt and default-password XLS in [spreadsheet-cells.md](spreadsheet-cells.md)).

## HTML / text

Kept separately: mail (MHTML header blocks, mbox, forwarded mail and attachment verdicts, meeting-invitation events) in [mail.md](mail.md); HTML blocks (aside, quote blocks, checklists, item/value tables whose name cell is a th), `aria-hidden` on an app root, noframes, lazy-loading placeholder pictures, MHTML frame warnings, inline SVG labels and `data:` URI pictures embedded in MD in [html.md](html.md); character-encoding detection (BOM, UTF-8, CP949, declared charset, statistical guess, text detection) in [encoding.md](encoding.md).

| For large HTML only the front part (starting at limit × 2 characters) is parsed first, and if that alone exceeds the limit it stops (`html._extract_front`). ## Image files

| Decision | Why | Pinned by |
| --- | --- | --- |
| A multi-page TIFF is split by `image.split_tiff_pages` into a one-page TIFF per page (lossless), one STANDALONE picture per page section. Up to `image.MAX_TIFF_PAGES` (1,000) pages, the decoded-pixel limit per page, a total over pages of `_MAX_TIFF_PIXELS` (10× the decoding limit; 100 pages of 10,000×10,000 in 650 KB took 9 s), and a warning when it stops at a corrupted or too large page. The number of pictures to describe is `max_images` as for other pictures. Animated GIF and AVIF (brand `avis`, `image.is_image_file`) give the first frame only (a frame is not a page). Known accepted gap: a thumbnail IFD in the main IFD chain is read as a page too | Only the first page was read, so the remaining pages of fax and scan bundles disappeared without a warning. Animated AVIF was not detected as an image and was rejected. Splitting is decoding, so it lives in `image.py`, which owns the decoding limits (exception to the dependency direction in [core.md](core.md)) | `test_image.py::TestMultiPageTiff`, `test_core_front_cut_and_tiff_pixels.py::TestMultiPageTiffPixelTotal`, `test_core_image_and_assembly.py::TestAnimatedAvif` |

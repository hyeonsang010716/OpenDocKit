# Mail decisions

Deliberate decisions of mail extraction (.eml, .mht mail, mbox) (the mail unpacking in `_mail.py` and `_mail_calendar.py`, `html._extract_mail`). Split off from [extractors.md](extractors.md);
the rule is the same: do not revert the decisions in this table. To change one, change its pinning test first and write the reason in the same row. Mail/MHTML detection and
the headers are in the MHTML and reinforced-mail-detection rows of [detect.md](detect.md).

| The MHTML header block is walked line by line by `_mime_header_block`. No regular expression matching the whole block and no nested quantifiers of the form `(?:…+…)*` are used. The block is looked for within the first 256 KB (`_mail.MIME_HEAD_BYTES`), and a leading mbox separator line (`From sender …hh:mm…`) is skipped only when a header block follows it (`_mail.mime_start`, common to mail and MHTML). With an 8 KB range, Office 365 mail with long headers and .eml starting with a `From - date` line were text with the base64 as is. Of a multi-mail mbox only the first mail was read | `test_detect.py::TestMhtml::test_prose_with_many_indented_lines_is_decided_in_linear_time`, `test_folded_header_lines_and_crlf_still_make_an_mhtml`, `test_blocks_that_are_not_header_blocks_are_not_mhtml`, `test_core_mail_and_detect.py::TestMailWithALongHeaderBlock`, `TestMailWithAnMboxFromLine`, `test_core_mail_parts_and_icons.py::TestMailboxWithSeveralMails` |

The search for body parts (`_mail_parts`) does not descend into forwarded mails. Even when the outside is plain text, if a forwarded mail has only an HTML body or there is an HTML body outside alternative (HTML body or footer of a mixed; `_mail.mail_html_outside_alternative`), the HTML extractor is used (`html._extract_mail`) — reading only plain text made that HTML body disappear without a warning (`TestForwardedMail::test_forwarded_mixed_mail_keeps_both_its_plain_and_html_bodies`, `test_forwarded_alternative_with_an_html_footer_keeps_the_footer`). The charset of RFC 2047 words (headers, attachment names) uses the superset codec (EUC-KR → CP949, `_mail._header_codec`). | A meeting invitation in the mail body (a text/calendar part that is not an attachment) is put after the body as `Event:` (`Event (cancelled):` for METHOD:CANCEL, and for an event of its own STATUS:CANCELLED — `test_core_mail_bodies_and_events.py::TestCancelledEvent`) + a list of `- Title/Start/End/Location/Organizer/Attendees: value` (`_mail_calendar.mail_calendar_events`; `html._calendar_html` for HTML mail; forwarded mails too).

# Third-party sample files

All other samples in this folder are generated by `examples/make_samples.py`. No Python library writes the Hangul
formats, so these three files are public test documents from two Apache-2.0 licensed projects by neolord0:

| File here | Original | Project |
| --- | --- | --- |
| `table.hwp` | `sample_hwp/basic/표.hwp` | [hwplib](https://github.com/neolord0/hwplib) |
| `score-table.hwpx` | `testFile/tool/textextractor/Table.hwpx` | [hwpxlib](https://github.com/neolord0/hwpxlib) |
| `numbered-outline.hwpx` | `testFile/tool/textextractor/ParaHead.hwpx` | [hwpxlib](https://github.com/neolord0/hwpxlib) |

They are unmodified apart from the file name and are redistributed under the Apache License, Version 2.0
(<https://www.apache.org/licenses/LICENSE-2.0>).
